Methodological Note on Contiguous Batch Sampling:

Phase 1 extracted 300 evenly spaced offsets of 100 contiguous rows each across the 2.83M-row dataset. Because adjacent packets within a 100-row contiguous batch can belong to the same network session or temporal burst, row-level stratified splitting can place temporally adjacent flows across both train and test partitions, which may inflate tree-ensemble test metrics.
